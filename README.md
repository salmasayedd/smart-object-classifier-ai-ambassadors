# 🤖 Smart Object Classifier — AI Ambassadors Initiative

An AI-based computer vision application created as part of the **AI Ambassadors Initiative (سفراء الذكاء الاصطناعي)** in collaboration with the **National Telecommunication Institute (NTI)**. The project classifies 3 different objects in real-time using a web camera or uploaded images.

---

## 📌 Project Overview
* **Program:** AI Ambassadors Initiative (سفراء الذكاء الاصطناعي) - NTI
* **Goal:** Train a deep learning vision model to distinguish between 3 distinct objects in real-time.
* **Tool Used:** Google Teachable Machine (Standard Image Model).
* **Dataset:** 20+ images per class collected under varied lighting conditions and angles.

---

## 🎯 Classes Trained
1. **Cup:** Various mug and cup samples.
2. **Mobile:** Different smartphone models.
3. **Book:** Diverse range of book covers.

## 📊 Performance & Results
* **Accuracy:** Reached **100%** confidence scores during test previews for all trained classes.
* **Challenges:** Initial false-positives caused by background clutter and dramatic lighting shifts.
* **Optimization:** Improved accuracy by expanding dataset diversity, gathering varied angle perspectives, and testing against neutral background settings.
