# 🤖 Smart Object Classifier

An AI-based computer vision application created as part of the **National Telecommunication Institute (NTI)** practical assignment. The project classifies 3 different objects in real-time using a web camera.

---

---

## 📌 Project Overview
* **Goal:** Train a deep learning vision model to distinguish between 3 distinct objects in real-time.
* **Tool Used:** Google Teachable Machine (Standard Image Model).
* **Dataset:** 20+ images per class collected under varied lighting conditions and angles.

---

## 🎯 Classes Trained
1. **Class 1:** [أكتبي العنصر الأول بالإنجليزية - مثلاً Pen]
2. **Class 2:** [أكتبي العنصر الثاني بالإنجليزية - مثلاً Mobile]
3. **Class 3:** [أكتبي العنصر الثالث بالإنجليزية - مثلاً Cup]

---

## 📊 Performance & Results
* **Accuracy:** Reached **92% – 100%** confidence scores during real-time webcam preview testing.
* **Challenges:** Initial false-positives caused by background clutter and dramatic lighting shifts.
* **Optimization:** Improved accuracy by expanding dataset diversity, gathering varied angle perspectives, and testing against neutral background settings.
